**PDF reading:** `pdftotext -layout {path} -`. Empty → scanned doc flag. **Steps:** 1. Metadata (type, date, author, pages) 2. Section mapping (title, pages, summary) 3. Clinical data (diagnoses, causation, findings, capacity, treatment, prognosis, impairment) 4. Decisions (type, date, reasons, appeal, deadline) 5. Key quotes (adverse/specific, with page) 6. Flags (adverse, contradictions, pre-existing, surveillance, capacity disputes) 7. Chronology entries (dateable events) 8. Cross-reference existing extracts (contradictions, new conditions, capacity changes).
