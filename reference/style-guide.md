# Style Guide
**Dates:** letters "28 March 2026", data "2026-03-28". Never US format.
**Client refs:** first mention "Ms Sarah Chen", then "Ms Chen" / "our client". Client letters: first name after salutation OK.
**Legislative refs:** first use "section 103 of the Workplace Injury Rehabilitation and Compensation Act 2013 (Vic)", then "s103 of the WIRC Act" or "s103". Lowercase "section"/"s".
**Currency:** $150,000.00 | **Percentages:** 25% | **WPI:** 8% WPI
**Letter format:** letterhead → date → addressee → delivery method (BY EMAIL/POST) → salutation → bold subject (client + claim number) → body → Yours faithfully/sincerely → firm name bold → practitioner name/title
**Enclosures:** "Enc:" at bottom, list each
